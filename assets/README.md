# Screenshots to add

Add these images to this folder with exactly these filenames. The main README links to them.

| Filename | What to capture |
| --- | --- |
| `workflow-canvas.png` | The full canvas of the content pipeline workflow, all nodes visible |
| `input-example.png` | One row in the `Content` tab with `Status` set to `idea` (use sample data, not real topics you have not published) |
| `output-example.png` | The same row after the run, showing `drafted` and the draft text, or the Notion page |

Optional: `error-handler-canvas.png`, a screenshot of the error workflow canvas.

Check every screenshot for real email addresses, sheet IDs, or client names before you commit it.
